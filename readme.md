## 个人自用mpv配置

使用方法：  
解压mpv.lite.7z，进入installer文件夹右键mpv-install.bat以管理员身份运行，然后双击mpv.exe或双击视频文件即可  
如需使用vs相关功能需要下载vs.7z，解压后把所有文件放到mpv.exe同目录（如果解压完是一整个vs文件夹需要提出来，mpv.exe同目录有python.exe是正确的）
